# 有条理的拖延：用摆烂来拯救人生

我相信每个人或多或少在生活中都有过拖延症的体验，今天我也对拖延症有几句话要说，不过我想说的是“有条理的拖延法（Structured Procrastination）“。简单来说，就是用摸鱼的心态，干正事的活儿！

我们先来剖析一下拖延者的神奇心理：当你需要写一份五千字的报告时，突然发现整理书架是多么迫在眉睫，给绿萝浇水是多么富有诗意，甚至连削铅笔都能削出禅意。看，这就是拖延者的智慧：我们不是不做事，只是特别擅长用次要事务来逃避主要事务。没错，你可以把任务清单排个序。最上头放着"年度总结报告"这种让人头皮发麻的任务，下面依次是“回复客户邮件”、“整理报销单据”这类小事。然后神奇的事情发生了，为了不写报告，你会积极主动地把下面所有事情都做完！这样一来，你在上司眼中就成了“效率达人”，而实际上你只是用生命在逃避而已。

有人可能要说了：“那最重要的任务不就永远完不成了？”问得好！这里的精髓在于：你要把那些“看似重要实则弹性”的任务放在最上面。比如“了解公司新考勤制度”（其实晚两天也不会被开除），或者“研究数字化转型白皮书”（反正也没人真的会看）。职场中这类“纸老虎”任务比比皆是，就看你会不会挑。说白了，这需要一点自欺欺人的艺术。不过这对拖延者来说简直是最擅长的就是骗自己了。**用魔法打败魔法，用缺点利用缺点，这难道不是最高境界的人生智慧吗？**

举个栗子，以前纸质信件的时代，我肯定是把重要信件放在最显眼的地方，然后，逐渐就回被埋在最底下，而且偶尔会有几封信从桌缝掉下去，就此人间蒸发。不过如果真有什么急事，对方肯定会打电话来骂的。

现在虽然用电邮了，但情况其实差不多。收件箱里未读邮件常年保持在三位数，就像我家的储物间，东西放进去就基本告别江湖了。我发明了各种自欺欺人的方法：标星邮件、重要文件夹、紧急待办......最后这些分类全都变成了“眼不见心不净”的坟墓区。

最搞笑的是，有时候为了逃避写方案，我会突然变得特别勤快，秒回各种邮件。对方一定很惊讶：“这人工作效率也太高了吧！”其实，我只是在用回邮件的方式，逃避更可怕的任务。

现代科技还给我们拖延者带来了新挑战：点开一封邮件，里面有个链接；点开链接，又有个视频；看完视频，又推荐相关文章......两个小时后，报告还一个字没写。当然，破这种局也不是很难，比如，在饭点前查邮件，这样饿到不行的时候自然就停下来了。或者用笔记本时故意不插电源，等电量耗尽自动关机，看是你网页加载得快，还是我的电池掉得快！

总之，朋友们，既然我们注定要拖延，不如拖出风格、拖出水平。记住我们的口号：用摆烂的心态，卷死别人！只要套路深，拖延也能变成生产力工具。现在我要去整理书架了，因为...呃...我好像还有个邮件要写？明天再说吧！
