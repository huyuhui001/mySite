# 读后感之：前言

在2024年元旦之后，我阅读了约翰·森梅兹（John Sonmez）的两部著作，分别是《软技能：代码之外的生存指南（第2版）》与《软技能2：软件开发者职业生涯指南》。读完这两本书后，我内心产生了强烈的共鸣，不禁萌生了撰写读书感想的念头，这恰好也是作者所倡导的“输出型”学习方法的实践，于是便有了以下这些读后感。

仅凭技术技能，既无法成就辉煌的事业，也无法铸就灿烂的人生。如果我们只是按部就班地完成本职工作，那么作为软件开发者，我们或许能够勉强维持生计。但如果我们甘于平庸，那也无妨。

许多人怀揣着一个荒谬的幻想——总有一天，他们能够声名远扬、富甲天下，甚至两者兼得。他们幻想着奇迹会降临，让他们的所有愿望和梦想一并实现。

然而，现实是残酷的。生命中唯一可以确定的事情就是死亡，而要实现其他所有目标，都必须付出努力。在推进软件开发者职业生涯的道路上，有许多事情需要去做。

比单纯努力工作更为关键的是，我们要清楚自己该做什么，以及我们对目标的持之以恒与坚定承诺。

专注于“软技能”，诸如良好的沟通能力、以身作则的领导力、从失败中迅速恢复的能力，甚至是提升个人健康水平的能力，能够助我们突破自身的“玻璃天花板”。

厄尔·南丁格尔曾言：“工作属于公司，而职业生涯属于我们自己。”如果我们认为自己是在为他人工作，那么我们对工作的动力和安全感早已丧失。职业发展的驱动力必须源自个体自身。

成功的软件开发人员之所以能够取得成功，绝非偶然。他们目标明确，为了实现目标，制定了坚实可靠且经过深思熟虑的计划。

如果我们真的渴望在竞争激烈的软件开发领域崭露头角，那么我们所要做的，远不止拥有一份光鲜亮丽的简历以及偶然获得的工作机会。我们需要主动管理自己的职业生涯。
